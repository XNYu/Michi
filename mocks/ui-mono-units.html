UI = IBM Plex Mono

The full UI is locked to IBM Plex Mono. Only the small "system" elements toggle: keyboard hints (⌘0, ⌘K), numeric badges (3, 12, 27), table number columns, status counters, and inline glyphs. Mode A keeps everything in IBM Plex Mono — perfectly unified. Mode B swaps these "system" elements to a different mono with better tabular numerals (Geist Mono) for visual contrast against the body text.
